# OTS Interactive Study Academy

Independent, unofficial study and practice website for academic preparation. Not affiliated with or endorsed by the U.S. Air Force, U.S. Space Force, or Officer Training School.

## Publish with GitHub Pages

1. Upload the reviewed public-edition `index.html` to the **root** of this repository (next to this README).
2. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)` and save.
3. The expected address is `https://lele4u2.github.io/OTS-ACADEMIC-STUDY/` after deployment.

## Privacy and course materials

Do not upload original Student Reader PDFs, internal course files, class rosters, instructor names, personal notes, or identifying metadata without verifying permission to distribute them. The reviewed website uses shorter subject reviews rather than republishing complete course readers. Check all content for accuracy, permissions, and privacy before sharing.

## Site files

This repository is prepared for a single-file static site: `index.html`. Do not upload the old ZIP archives or separate libraries. Progress stored locally in the browser is specific to that browser/device.
